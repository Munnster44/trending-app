Multi-District Membership Trending

Maintain independent membership histories for multiple districts and their squadrons.

Creating a new district makes a completely separate interface and history. Switching districts instantly changes the entry fields, tables and graphs.

README / Instructions

Purpose

This app tracks membership trends for multiple districts. Each district has its own squadron list, membership snapshots, graphs, table, CSV export and JSON backup.

1. Select or Create a District

  1. Use Active District to switch between districts.
  2. Select New District to create another district.
  3. Enter the district name.
  4. Enter each squadron on a separate line.
  5. Select Save District Setup.

2. Edit a District or Squadron List

Select the district, then choose Edit District / Squadrons. You can rename the district, add new squadrons, or remove squadrons. Removing a squadron also removes that squadron column from the stored history for that district.

3. Add a Membership Snapshot

  1. Select the district.
  2. Choose the snapshot date.
  3. Enter the membership number for each squadron.
  4. Select Save Entry.
  5. The entry count beside the district name confirms how many snapshots are stored for that district.

4. Edit or Delete an Existing Snapshot

Choose an entry from Select an existing entry. Load it, make changes, and select Save Entry. Use the delete buttons to remove a complete snapshot date.

5. Load a CSV

Load CSV into Active District imports data into the currently selected district. The CSV may use either of these layouts:

  • Date, Squadron 1, Squadron 2, ...
  • Squadron, Date 1, Date 2, ...

The app detects the squadron names from the file and builds the district interface from those columns.

6. Save an Individual District

After adding or changing entries, use Save Active District Files. This downloads a fresh CSV and JSON containing the current data for the selected district. Previously downloaded files are not automatically rewritten by the browser.

  • Save Active District JSON — JSON backup for the selected district.
  • Save Active District CSV — CSV export for the selected district.

7. Save All Districts

Save All Districts creates one JSON workspace backup containing every district, every squadron list, and all membership history. Use Restore All Districts to reload that workspace later.

8. Browser Storage

The app also saves the current workspace in your browser's local storage. This helps retain your districts between sessions on the same computer and browser. JSON backups should still be kept as your permanent backup.

9. Graphs

  • Graph 1 — total membership trend for the selected district.
  • Graph 2 — squadron trend lines, latest squadron comparison, or change by squadron.
  • Graph 3 — all squadron membership totals for a selected snapshot date.
  • Graph 4 — membership history for one selected squadron.

10. Printing

Select Print Graphs to create a printable report for the active district, including an individual membership-history graph for every squadron.

Recommended Backup Procedure

  1. Save your new membership entry.
  2. Use Save Active District Files for the district you just updated.
  3. Periodically use Save All Districts for a complete workspace backup.
